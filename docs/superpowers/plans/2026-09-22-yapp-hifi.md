# Yapp Hi-Fi Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v1 bar with the approved hi-fi: system-appearance pill (400 × 96) with every state from the wireframes, a first-run permissions window that re-checks every 2 s, a template menu-bar glyph with four variants, the "what can I say" hint, and the ⌥-glyph app icon.

**Architecture:** The hi-fi bundle from the Claude Design project replaces `src/yapp/ui/` verbatim. The existing `Bar` façade, `BarDisplay`, `Session`, and `barapp` stay; they gain the new API calls (`setCountdown(seconds, total)`, `setPermissions`, `setHint`, `refused` state), a one-way JS→Python bridge for the page's `yapp:action` events (Fix, Show log) via pywebview's `js_api`, a second pywebview window for `permissions.html`, and a `permissions.Watcher` poll on the session thread. The menu bar swaps template images per state.

**Tech Stack:** as plan 2 (pywebview 6.2, PyObjC, pynput), plus `yapp.permissions`.

**Spec:** `docs/superpowers/specs/2026-09-21-yapp-design.md` section 10, as amended by the approved wireframes and hi-fi in the design project (https://claude.ai/design/p/be45c375-77cb-4cdf-9646-2ea5843fa7ee).

- [ ] **Step 2: Implement**

```python
BRIDGE_JS = (
    "window.addEventListener('yapp:action', function (e) {"
    "  if (window.pywebview && window.pywebview.api) { window.pywebview.api.action(e.detail || {}); }"
    "});"
)


class Actions:
    """Exposed to the page as window.pywebview.api; the page's Fix / Show log links land here."""

    def __init__(self, on_action: Callable[[dict[str, Any]], None]) -> None:
        self._on_action = on_action

    def action(self, detail: dict[str, Any]) -> None:
        self._on_action(dict(detail or {}))
```

`countdown` sends `(round(seconds,1) if seconds is not None else 0, total)`; `hint` passes the value through `_j`. `appearance()` calls `setAppearance()`.
